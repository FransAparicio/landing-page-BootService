# Aprendiendo Git & GitHub
- Estos son los pasos para empezar con Git.
## Paso 1
- Inicializar el nuevo repositorio

```
git init
```
- Directorio de Trabajo donde se escribe el codigo

## Paso 2
- Enviar los nuevos archivos o archivos modificados al area de preparacion.
```
git add index.html
o
git add .
```
- El Arera de Preparacion es donde se prepara los cambios.

## Paso 3
- Registrar un comentario o descripcion del cambio realizado antes de subit a git
```
git commit -m "Proyecto Base"
```

# Github

```
git remote add origin https://github.com/FransAparicio/landing-page-BootService.git

```
